# Detetive Virtual Tab

Jogo de detetive online para 2 a 6 jogadores, no navegador (Android e iPhone).

- Telas: arquivos desta pasta (hospedados na Vercel)
- Servidor: Supabase (salas, tempo real, pistas e soluções)

As pistas e soluções dos casos ficam **somente no Supabase**, protegidas. Elas não estão nestes arquivos.
